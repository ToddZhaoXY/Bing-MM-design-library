## Deliberate boundaries

- 14 SDL adapters are partial and three are candidate. Local catalog validation is
  not live Mosaic visual/runtime acceptance; blur, overlays, platform chrome and
  opaque action/resource contracts have explicit gaps.
- Authentication, generation, upload, sharing, download and navigation are host
  integration points. The source reference-image toggle uses source sample art;
  it does not upload the user's files.
- The source is desktop-sized. Fit is a preview scale, not a claim of a separately
  designed mobile layout. No exhaustive accessibility audit or pixel-diff acceptance
  across every source variant was performed.
- Source Action row typed metadata remains broken in Figma. Four observed named
  configurations are preserved without invented axes. Source variable aliases
  are not a fully resolved design-token dictionary.
- No Figma edits, git push, remote deployment or npm publication was performed.
