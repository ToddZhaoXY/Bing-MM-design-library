# Video ACF architecture

The screenshot allowlist selects 15 Figma pages. Actual node/variant readings and
design-context screenshots produce checked source fragments. The registry drives
the navigation, documentation, property controls, public React renderers, JSX,
page-state validation and flattened Mosaic SDL adapters.

Molecules compose into three cells and four supplied page organisms. Two source
gap routes expose their source status and links without fabricated layouts. Shared
page chrome is separate from portable answer content. The full source designs
include desktop and mobile variants, selected through explicit configurations.

`values` holds registry properties; `live` holds current interaction overrides.
Copying JSX, exporting SDL and restoring JSON use those effective values. Hover and
focus are visual interaction states; real media, authentication and product
navigation remain application integration points.

The page assembler validates imported versions, slugs, property types, enum values,
IDs and payload bounds. It supports reorder/remove/undo and a static DOM snapshot.
The portable HTML exporter embeds same-origin static assets and used Roboto fonts,
retaining the font license; it reports failed or external resources explicitly.
It does not copy React interaction code or embed video streams.

Mosaic uses the inherited 32-component catalog. Complex overlays, clipping,
scrubbing, hover preview, playback, product chrome and opaque action contracts are
explicit portability limits. No undeclared Video/Grid/Carousel SDL node is invented.

Vite uses relative base paths and HashRouter. Only runtime `public/figma` assets
are copied to dist; original images and source export directories are excluded.
Source archives omit node_modules, dist, build caches and original large images.
