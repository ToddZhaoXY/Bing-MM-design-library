## Design Context

### Users and purpose

This is the user's MM Image / AIGC / Video design-system workbench. The existing
jobs are component inspection, variant editing, page assembly and React / SDL
export. The user explicitly requests a separate copy, preserving all content and
behavior while making its UI and layout more premium, readable, simple and airy.

### Aesthetic direction

Quiet, precise, spacious. The user now explicitly requests a new first-visit
overview with a refined animated masonry component showcase. Use existing
library assets and direct links to independent library pages. Keep the existing
library internals and the refined documentation/editing theme.
The Figma components themselves are specimens, not chrome to redesign.

Palette: paper #fcfcfd, navigation #f5f6f8, ink #202631, secondary #596372,
hairline #e0e4ea, restrained blue #2859a6. Native sans typography is intentional
for a cross-platform design tool: SF Pro / Segoe UI, with original specimen fonts
unchanged. No new font downloads, illustrations, branding or copy.

### Layout

Homepage revision 2026-10-21: a single full-height canvas. Only a large centered
"MM Design Libraries" wordmark and the exact existing description remain in the
foreground; the three library links sit at the upper right. Source component
previews continuously travel up/down in surrounding columns behind a soft mist.
Remove eyebrow, duplicate brand, library list, showcase heading and footer.
Use a tiny accessible pause icon, no large motion toolbar. Do not stop motion
on gallery hover. Use seamless linear loops (roughly 20-30px/second), respect
reduced-motion, and verify actual displacement and pause/resume in the browser.
Follow-up: cap the wordmark at 5rem and keep the desktop mist bounded to
1280 × 480px. Every preview is a native link to its corresponding component.
Keep overlays pointer-transparent and loop copies pointer-clickable, but out
of the tab order. Keyboard focus exposes a stable, scrollable original column.

One 64px system switcher above the original apps. A quiet 236px navigation rail,
readable left-aligned document column, and well-separated canvas / property
zones. Five type roles: 12px metadata, 14px controls, 16px prose, 20px section
headings and 32px page headings, specified in rem. Use 4/8/12/16/24/32/48 spacing.
On smaller screens reflow the tool panels without removing controls.

### Principles

- Keep every original child-library source file and its text / data byte-identical.
- Add a first-visit homepage and use normal standalone navigation, not iframes.
- Add a CSS-only chrome theme at the composition/build layer.
- Do not redefine original CSS variables or inherit new typography into previews.
- Preserve source-scale components, exported HTML appearance, React and SDL.
- Use whitespace and type hierarchy instead of decoration or nested cards.
- Preserve the approved Design-Systems-Hub and its delivery packages unchanged.
