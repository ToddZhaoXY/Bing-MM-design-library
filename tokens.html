Non-negotiable principles

  • Use semantic SMTC tokens with explicit fallbacks — never hardcode design values
  • Use @container serp and the 12 → 8 → 4 → 2 column system
  • Cards stay flat at rest; elevation is reserved for interaction and system UI
  • Dark mode resolves automatically through semantic tokens
  • Load only the references required for the task through progressive disclosure

Overview

Two tasks, one skill.

Structured Generation — Fast, accurate, coherent

Generate cards, magazines, and layouts from a single prompt. Every output strictly follows the card and magazine specifications defined in the Bing Design Skill — tokens, spacing, typography, and layout rules are all enforced automatically, delivering high accuracy and strong visual coherence at speed.

Design Exploration — News Go Wide

An open-ended design exploration using the skill as a creative tool — from spec to multiple outputs in three steps.

1

Prepare the Figma Reference

Organize the current design file — summarize the PM spec, identify the existing vertical module (News Events + Related News), and define the design goal: redesign it into a single wide-format module.

2

Prompt Claude Code with Context

Distill the design goal into a natural language prompt, provide the Figma link, and let Claude fetch the full context via MCP. The skill handles the rest — planning the approach, then generating multiple design directions.

3

Review Multiple Outputs

Tips

Overview

Getting the most from your skill.

Working with the skill

Plan Mode First
Use Plan Mode to describe your requirements clearly before execution. This significantly reduces errors and back-and-forth iterations.
Work in Steps
Break tasks into stages — get the structure right first, then fill in real data later. Incremental progress beats one-shot perfection.
Write a Good CLAUDE.md
When working on a dedicated project, a well-written CLAUDE.md gives the AI persistent context and dramatically improves output consistency.
Accept Minor Variance
Small detail differences are normal — not every deviation is a skill bug. Prompts in English tend to yield more predictable results.
